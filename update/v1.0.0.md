**ZENKAI Power!**
---
**Version: 1.0.0**

**Added**
- Native game support
  - Windows, Linux and Android platforms.
  - Keyboard and mouse support for desktop versions.
  - Touchscreen support for mobile version.
  - Widescreen support for battles and menus.
  - Additional video options, including support for higher resolutions and frame rates.
  - Replaced texture-based menu text with native text: menus, dialogs and battle text.
- *Dragon Net Battle* restoration from exclusive Wii version mode.
  - LAN and online multiplayer with casual and ranked battles.
- New features
  - Unlockable *Disc Fusion* modes.
  - Expanded in-game options menu.
  - Keyboard/Mouse and Gamepad options, including alternative clash input option.
  - Virtual gamepad for battle in mobile version.
  - Autosave functionality.
  - Japanese and US voice actor credits in *Character Reference*.
  - Game edition selection between **Sparking! METEOR** and **Budokai Tenkaichi 3** to change artwork and soundtrack.
  - UI text filter to stop displaying ®, ™, and © symbols, including in characters names. 
- Original-game fixes
  - Mission 100 fifth-character selection exploit.
  - Electrical aura disappearing after rematches.
  - CPU switching incorrectly blocked when transformations are disabled.
  - Incorrect default AI selection.
  - Incomplete random-number generator refresh.
  - Sound-command queue overflow.
  - Battle-memory allocation overflow.
  - Crash from exceeding pending file requests.
  - Music stereo channels being collapsed to mono.
  - Some English text corrections like "x20 Kaiken Kamehameha" -> "x20 Kaioken Kamehameha" and "Freiza" -> "Frieza".
- *Sparking! Changes* - additional content (enabled by default, optional to disable):
  - New character and stages unlock progression system through *Dragon History*.
  - New *Dragon World Tour* unlock progression system through *Dragon History* and rebanlanced rosters, including more variety of characters and DP-weighted battles results.
  - Training now supports team battles with a new *Training Settings* submenu on *Training* with Health, Ki, Blast Stock, and Switch Gauge Regeneration toggles.
  - Captain Ginyu Body Change move was revised and a new feature was added.
  - Goku Super Saiyan 2 moveset was changed.
  - Oozaru transformations for characters that can use Power Ball now uses the full moon when available in the stage.
  - Cell (Perfect Form) now uses a new animation sequence when transforming from Perfect Cell.
