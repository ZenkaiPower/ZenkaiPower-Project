**ZENKAI Power!**
---
**Version: 1.1.1**

**Changed**


- Android mobile version:
  - First startup now waits for the user to select game folder.
  - The virtual analog stick now uses animated game artwork.
  - Touchscreen swipes now scroll the main menu and character/stage/music selectors, including team and online selection. Horizontal swipes move focus left or right.
- *World Tournament*:
  - Extra Saibamen, Cell Juniors and Frieza Soldiers fill bracket slots only after all other eligible choices run out.
  - CPU selection prefers eligible non-giant forms that are not already in the bracket before selecting their giant counterparts.
- As part of the original-game fix pack, Mission 80, Mission 100 and Survival's third course uses the opening soundtrack as BGM loop.
- Online battles now use Sparking! Changes when both players' saves enable them, otherwise they use Classic Mode.

**Fixed**

- Interpolation:
  - Improved menu interpolation when FPS drops, with steadier frame timing and fewer delayed or duplicate frames.
  - Reduced interpolation overhead when menus run at their native frame rate.
  - Improved interpolation stability for HUD elements and other 2D sprites by separating screen-space geometry from world geometry and preserving stationary sprite matches.
- Android mobile version:
  - Keep the device keyboard closed and accept taps on the in-game keyboard.
  - Back button and back gesture now perform the same in-game cancel action as a two-finger tap.
  - Triangle + R1 touch input now presses Triangle first, then R1.
- *Evolution Z* items entries:
  - The full visible item row responds to clicks and taps in *Character Edit* and in the *Item Shop*'s purchase and collection lists. 
  - Item scrollbars can also be dragged with a mouse or touchscreen.
- The *World Tournament* bracket and character chips now slide fully off the right edge on widescreen when the result banner appears.
- Save game data now write in the background to prevent the screen and saving animation from freezing.
